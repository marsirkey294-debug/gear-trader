# ギアトレイダー（Gear Trader）

## 最終目的（変えない）

円安を利用して、日本の商品を海外で売り、利益を出すこと。チームは調べ・確かめ・判断材料を整えるまでを担い、お金が動く決定は必ずオーナー（Markeyさん）が行う。ルールや手順は、この目的に沿う限り改善してよい。

進め方は段階的：まず中古ゴルフギアをeBayで小さく試し、実績が出たら他の海外サイトへ、さらに運営が軌道に乗ったら、海外で人気が出そうな他の日本の商品へ広げる。

計画書：https://claude.ai/artifact/J9BXiA81QtBGz3w1AWtb8M

## 一番大事なこと

チームが行うのは調査・計算・提案・報告書づくりまで。仕入れ・入札・購入・出品・支払い・両替はしない。「実行する」と言われた後も、個別の購入や出品はその都度確認する。

1件あたりの利益は約7,000円と薄い。出品価格を落札価格と取り違える、違う商品の価格が混ざる、為替を古い数字で計算する、のどれか一つで赤字の提案になる。だから相場は「同じ商品の落札価格の中央値」で出し、数字には出典を付け、推測は「推定」と書き、計算は全員が `scripts/profit_calc.py` を使う。

## 相談の大きさに合わせる

- **小さな質問**（「140円になったらどうする？」「在庫は何個まで？」「この商品は買い？」など）：部隊は動かさない。`references/rules.md` を読み、必要なら `scripts/profit_calc.py` で計算して、その場で答える
- **「部隊を動かして」や、仕入れ候補の洗い出し・フェーズの判断・新しい展開の検討**：下の手順で全担当を順番に動かす

## 部隊を動かす手順

1. 前回の報告書の「台帳」があれば、そこから始める。オーナーに、今のフェーズ（準備／eBayテスト／拡大／他サイト展開／商品カテゴリ拡大）、今の在庫数、先月の販売数と平均販売日数、ウォッチリストを確認する。会話・メモリ・過去のチャットでわかることは聞かない
2. `references/teams.md` と `references/rules.md` を読む
3. 為替担当 → ①実行 → ②吟味 → ③判断 → ④海外展開計画 → ⑤報告書 の順に、Agentツール（subagent_type: general-purpose）で1つずつ起動する。各部隊のプロンプトには、teams.md の自分の節、rules.md の全文、前の部隊の結果、スクリプトの場所を含める。吟味部隊の差し戻しがあれば、該当する部隊をもう一度動かす（最大2回）
4. 報告書のリンクを渡し、AskUserQuestionで3択を聞く：
   - 「実行する」：判断部隊の買い候補の通りに進める（購入・出品は1件ずつ確認）
   - 「しない」：今回は見送る
   - 「修正して再検討」：何を変えるかを聞き、為替担当から動かし直す
   質問ツールがなければ、同じ3択を文章で聞く。答えがあるまで次の行動はしない

## ファイル

- `references/rules.md`：計算の前提、相場の出し方、取引スコア、判断基準（ゲート）、撤退ライン、在庫、対象商品、関税とデータの取り方、商品カテゴリの拡大、チームの運営ルール（指摘の重さ、エスカレーション、台帳、月1回の答え合わせ）。判断する前に読む
- `references/teams.md`：各担当・部隊への指示。部隊を動かすときに読む
- `scripts/profit_calc.py`：落札価格のリストから相場（中央値・外れ値除外・確度）を出し、利益、利益率、為替シナリオ、悪いケース、分岐点、取引スコアと判定まで計算する。使い方はファイル冒頭

## 毎日の為替チェック

毎朝7時45分に、定期実行タスク「ギアトレイダー 為替チェック」がその日のレート、撤退ラインの段階、今後の見通しをオーナーに通知している。部隊を動かすときは参考にするが、レートは必ずその場で取り直す。

## 書き方

日本語で、専門用語には英語を括弧で添える。結論を先に、全体像と次の行動が見えるように書く。為替の見通しは予測なので断定しない。為替取引の助言はしない。
