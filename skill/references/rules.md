## 1. 計算の前提

計算は `scripts/profit_calc.py` で行う（部隊ごとに式がずれるのを防ぐため）。

- 利益 ＝ ドル価格×当日レート×0.83（eBay手数料約15%＋為替手数料約2%を引いた残り）− 送料 − 梱包 − 仕入れ値 ＋ 消費税還付
- 送料の目安：ヘッドは米国5,000円・英国と豪州3,500円（2026年11月の調査。日本郵便は2027年2月1日に値上げ）、シャフト6,000円・完成品7,000円・アイアンセット10,000円（未調査の仮の値）。梱包は500〜1,000円。商品に `"dest": "uk"` などを付けると送り先別に計算する
- 米国宛ては関税の前払い（DDP）が必要。関税率はヘッドの原産国で決まるので、検品で原産国を確かめ、毎回その税率を利益から引く
- 返品条件は「30日・返送料は買い手負担（説明と違う場合は当方負担）」。返品率5%以下が3か月続いたら無料返品を検討する
- 状態の等級・撮影・梱包・英語の返信は docs/作業手順書.md に従う。手順書の「仕入れないもの」（凹み・割れ、スリーブ破損、ネジ山の傷み、シリアル削り、偽物の疑い）に当たる出品は、出品写真で確かめられない場合も含めて買い候補にしない
- 消費税還付は、課税事業者から仕入れた場合のみ（個人出品者からの仕入れには消費税が含まれていないため）
- オーナーから実費（実際の送料・手数料）が示されたら、スクリプトの定数を直してから使う
- eBayの価格は「落札価格（sold）」を使う。出品価格（asking）は実際には売れていない値段なので、使う場合は必ず「出品価格」と明記する
- 「利益率」は利益÷仕入れ値（投資に対する利益率＝ROI）。売上に対する利益の割合ではない

## 2. 相場の出し方（同じ商品だけを比べる）

GitHubで公開されている転売・相場ツールで、精度が高いものに共通していたやり方を取り入れている。理由は一つで、「違う商品の価格が混ざった平均」は、もっともらしいのに間違った相場になるから。

- **相場＝一致した落札価格の中央値。** 平均ではなく中央値を使うのは、極端に高い・安い1件に引っ張られないため。外れ値は四分位範囲（IQR）で除く（スクリプトが自動で行う）
- **一致した落札が3件未満なら「データ不足」。** 価格として扱わず、判定は見送り。2件では偶然の高値・安値と区別できない
- **落札価格がなければ、出品価格の中央値×0.8で代用し、確度は「低」。** 出品価格は売れていない値段なので割り引く
- **別の市場として扱い、混ぜないもの：** ヘッドのみ／完成品、新品・未使用／中古、右用／左用、ロフト違い、日本仕様／米国仕様、モデル世代違い（G440とG440 K、G430とG440など）
- **一致しない出品として除くもの：** 複数本のまとめ売り、ヘッドカバー・レンチの有無が大きく違うもの、割れ・凹み・修理品・ジャンク、カスタム塗装、「互換」「レプリカ」「ノーブランド」と書かれたもの、ツアー支給品（Tour issue。相場が別物）
- **落札価格は「商品代＋買い手が払った送料」の合計で比べる。** 送料別の落札は送料を足してから `sold_usd` に入れる。買い手は合計で比べるため、商品代だけでは相場を低く見積もる
- **送料の見せ方（テスト中の方針）：** 米国向けは送料込みの価格で「送料無料」、英国・豪州向けは送料を別に表示（送り先ごとに計算）。ゲート②の期間に、同じ型番を「送料無料」と「送料別」で出し、売れるまでの日数を比べて決める（決定はオーナー）
- **確度の目安：** 落札8件以上＝高、3〜7件＝中、出品価格のみ＝低
- 各商品について、使った落札の件数と、除いた出品の数と理由を記録する（吟味部隊が確かめられるように）

## 3. 取引スコアと判定

利益率だけで決めず、「悪いケースでどれだけ損をするか」と「データの確かさ」で減点する。利益率が高くても、相場が大きくぶれる商品やデータが少ない商品は危ないため（公開事例のBUY／WATCH／SKIP方式を参考にした）。

- スコア（1〜10）：当日の利益率15%で5点を基準に、5%ごとに±1点。悪いケースで赤字なら−2、10%未満なら−1、悪いケースの損失が仕入れ値の1割を超えたら−1、確度「低」は−1
- 悪いケース＝10円円高、かつ相場がばらつきの半分だけ下がった場合
- 判定：**買い候補**（スコア7以上かつ当日15%以上）／**様子見**（4〜6。値下がりを待つ、データを増やす）／**見送り**（3以下、またはデータ不足）
- 「様子見」の商品はウォッチリストに入れ、次回の部隊で仕入れ値や相場が動いたか確認する

## 4. 判断基準（ゲート）

| ゲート | 条件（すべて満たす） |
| --- | --- |
| ① 準備 → eBayテスト | 古物商許可あり、eBayセラー口座開設済み、送料の実費が判明 |
| ② eBayテスト → 拡大 | 平均利益率15%以上、販売率70%以上、平均販売日数30日以内、返品率5%以下、15件以上の販売実績 |
| ③ 拡大 → 他サイト展開 | ②の基準を3ヶ月維持、月の販売数が安定 |

| ④ 他サイト展開 → 商品カテゴリの拡大 | ③の後、eBayと他サイトの合計で②の基準を3ヶ月維持、運営（仕入れ・撮影・梱包・発送）が手順として回っている |

- 仕入れ候補は「取引スコアで買い候補」、つまり当日レートで利益率15%以上、かつ悪いケースでも大きな損が出ないもの。1件の利益が薄い（約7,000円）ので、為替の小さな変動で赤字にならない余裕を持たせるため
- 15件以上を条件にするのは、数件の結果では偶然の当たり外れと区別できないため

## 5. 撤退ライン（ドル円の30日平均で判断）

| ドル円（30日平均） | 対応 |
| --- | --- |
| 150円以上 | 通常どおり |
| 145〜150円 | 利益率15%を割る商品の仕入れを止める |
| 135〜145円 | 仕入れを減らし、在庫の上限を半分にする |
| 135円未満 | 新しい仕入れを止める（撤退）。在庫は売り切る |
| 125円未満 | 全商品がほぼ赤字。在庫の売り切りを急ぐ |

- 30日平均で判断するのは、一時的な円高のたびに止めたり再開したりすると、仕入れの機会と手間の両方を失うため
- 2026年11月時点の分かれ目（利益ゼロの為替）：G440 LST 約133円、G430 MAX 10K 約124円、G440 SFT 約121円。商品が変わったら判断部隊が計算し直し、撤退ラインの見直し案を出す（変更はオーナーの承認後）
- 撤退＝新規仕入れ停止＋在庫の売り切り。在庫を捨てる意味ではない

## 6. 在庫のルール

在庫を少なく保つ理由は3つ。円高で在庫の価値が目減りする、新モデル発売で前モデルが値下がりする、売れ残りは次の仕入れに回せないお金になる。

- 在庫の上限は「先月売れた数」。eBayテストの1ヶ月目は5個まで、以降は売れた分だけ補充（テスト期間は最大10個、拡大期は最大30個）
- 同じモデルは3個まで（1モデルの相場下落で損が膨らまないように）
- 30日売れなければ値下げを検討、60日売れなければ損切りを提案
- 在庫が月の販売数の2ヶ月分を超えたら、仕入れ停止を提案（売れるペースが落ちているサイン）
- 平均販売日数：30日以内なら上限を少しずつ増やす、30〜45日は現状維持、45日超は上限を減らして値付けや商品を見直す
- 30日平均が145円を下回ったら、在庫の上限を半分にする
- 為替担当の円高シナリオで次の段階に下がりそうなら、先回りして在庫を減らす案も並べる

## 7. 対象商品と仕入れの注意

- ブランド：PING、キャロウェイ（Callaway）、テーラーメイド（TaylorMade）、タイトリスト（Titleist）、その他eBayでの売れ筋、日本の地クラブメーカー
- 中心はドライバーのヘッド単体。完成品は価格差が小さく赤字になりやすい（G440 MAX完成品で約−22%）
- シャフトは「日本でしか売っていないモデル」だけが対象。米国でも流通しているもの（例：TENSEI PRO WHITE 1K）は日本の方が高く、赤字になる
- 利益が大きい可能性がある候補：地クラブのアイアン（三浦技研など）、日本仕様シャフト、大手の日本限定モデル。ただし多くはeBay側の数字が出品価格なので、落札価格で確かめてから判断する
- 三浦技研・スコッティキャメロンなど偽物の多いブランドは、実績のある店舗からの仕入れだけを候補にする
- 中古品を継続して仕入れて売るには古物商許可が必要

## 8. 米国の関税と、データの取り方のルール

- **米国向けの関税を毎回確認する。** 米国は2025年8月に少額輸入の免税（de minimis、800ドル以下）を停止し、2026年にも関税の仕組みが変わっている。買い手が払う関税が上がると、eBayでの売れ行きや相場が下がる。実行部隊は部隊を動かすたびに、日本から米国への発送にかかる関税の現状と、誰が払うか（買い手負担のDDUか、売り手負担のDDPか）を出典付きで確認し、相場への影響を書く
- **eBayのデータは公式の方法で取る。** 自動でページを読み取る仕組み（scraping）はeBayの利用規約に反するため、作らない・使わない。使うのは、オーナーがサインインしたブラウザで見られる落札データ、eBayの公式API（出品中の価格はBrowse API、落札価格はMarketplace Insights API＝eBayの承認が必要）、公開されたページの検索結果
- ヤフオクや中古ショップも同じ考え方で、公開ページを見る範囲にとどめる

## 9. 商品カテゴリの拡大（フェーズ4）

ゴルフギアで運営が軌道に乗ったら、同じ仕組み（円安を利用して日本の商品を海外で売る）で、海外で人気が出そうな他の商品へ広げる。オーナーの方針。

- **始める条件：** ゲート④を通ってから。ゴルフで手順（仕入れ・撮影・梱包・発送・問い合わせ対応）が固まる前に商品を増やすと、どこで損をしているのか分からなくなるため
- **1カテゴリずつ試す。** 新しいカテゴリは、eBayテストと同じ条件（在庫5個から、15件以上の販売実績で判断）で小さく始める
- **候補の選び方（ゴルフで効いた条件と同じ）：**
  1. 日本でしか買えない、または日本の方がかなり安い（日本仕様、日本限定、日本製）
  2. 海外で「日本製」「日本限定」に価値を感じる買い手がいる（落札実績で確認）
  3. 一致した落札が3件以上取れて、相場が出せる
  4. 小さく軽く、壊れにくい（送料が利益を食わない）
  5. 偽物の見分けがつく、または信頼できる仕入れ先がある
  6. 輸出・輸入の規制や、eBayの出品禁止・制限に当たらない（刃物、電池入りの製品、化粧品・食品、ブランド品などは事前に確認が必要）
  7. オーナーや仲間に目利きの知識がある（知識の差が価格競争を避ける一番の武器になるため）
- 候補カテゴリの評価にも `scripts/profit_calc.py` と取引スコアを使う。送料の区分が合わないときは、近い区分を使い、実費が分かったら定数を直す

## 10. チームの運営ルール（公開スキルの成功パターンから）

GitHubで公開されている人気のスキル集（alirezarezvani/claude-skills の human-gate、agent-harness、skill-retro）に共通していた「AIが自分の仕事を自分で合格にしない」仕組みを取り入れている。

- **指摘には重さを付ける。** 吟味部隊の指摘は、重大（BLOCKER：これが直らないと判断できない）／大（MAJOR：結論が変わりうる）／小（MINOR）／参考（NOTE）の4段階で書く
- **重大・大の指摘が残っている商品は、買い候補にしない。** 判断部隊は、その商品を「様子見」以下にする
- **差し戻しは2回まで。それでも直らなければ、合格扱いにせずオーナーに上げる（エスカレーション）。** 報告書に「未解決」として残す
- **部隊は、自分が判定される基準を変えない。** 利益率15%、撤退ライン、在庫の上限などの数字を変えられるのはオーナーだけ。部隊は見直し案を出すところまで
- **台帳を残す。** 報告書の最後に「台帳」として、在庫・ウォッチリスト・今回の判断・オーナーの決定を書く。次回はこの台帳から始めるので、毎回ゼロから聞き直さなくて済む
- **月に1回、振り返る（予想と実績の答え合わせ）。** 販売実績が出たら、予想した相場・利益・販売日数と、実際の数字を比べる。ずれが大きいルール（送料の目安、出品価格の割引率0.8、スコアの基準など）は、根拠となる販売実績を添えて見直し案を出す（変更はオーナーの承認後）
